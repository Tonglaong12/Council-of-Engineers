ตารางค่าคงที่และสมการพื้นฐานวิศวกรรมเคมี

1. ค่าคงที่สากล (Universal Constants)

  • ค่าคงที่ของแก๊ส (R) = 8.314 J/(mol·K) = 0.08206 L·atm/(mol·K) = 1.987 cal/(mol·K)
  • ความเร่งเนื่องจากแรงโน้มถ่วง (g) = 9.81 m/s²
  • ความหนาแน่นของน้ำบริสุทธิ์ (ρwater) ≈ 1,000 kg/m³ = 1 g/cm³
  • ความดันบรรยากาศมาตรฐาน (1 atm) = 101.325 kPa = 1.01325 bar = 760 mmHg
  • อุณหภูมิสัมบูรณ์ T(K) = T(°C) + 273.15

2. อุณหพลศาสตร์ (Thermodynamics)

  • กฎข้อที่ 1 (ระบบปิด): ΔU = Q + W | (ระบบเปิด Steady-state): ΔH + ΔEk + ΔEp = Q + Ws
  • ประสิทธิภาพวัฏจักรคาร์โนต์ (Carnot Efficiency): ηmax = 1 - (TC / TH)
  • สมการของอองตวน (Antoine Equation): log P* = A - B / (T + C)
  • กฎของราอูลต์ (Raoult's Law): yi P = xi Pi* และค่าความระเหยสัมพัทธ์ αAB = PA* / PB*

3. กลศาสตร์ของไหล & การถ่ายโอน (Transport & Unit Ops)

  • Reynolds Number ในท่อกลม: Re = (ρ v D) / μ
  • การถ่ายโอนความร้อน: Q = U A ΔTlm โดยที่ ΔTlm = (ΔT1 - ΔT2) / ln(ΔT1 / ΔT2)
  • สมการ McCabe-Thiele (Rectifying section OL): y = [R / (R + 1)] x + [xD / (R + 1)]

4. จลนพลศาสตร์และเครื่องปฏิกรณ์ (Kinetics & Reactors)

  • Batch (Constant V): t = CA0 ∫ dXA / (-rA)
  • CSTR: V / FA0 = τ / CA0 = XA / (-rA,exit)
  • PFR: V / FA0 = τ / CA0 = ∫ dXA / (-rA)
  • ปฏิกิริยาอันดับ 1: CA = CA0 e-kt (Batch/PFR) และ XA = kτ / (1 + kτ) (CSTR)
